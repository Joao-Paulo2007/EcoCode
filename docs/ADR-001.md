# ADR-001: Construir o módulo como aplicação de terminal em Java com Maven

- **Status:** Aceita
- **Data:** 2026-10-06
- **Autores:** Grupo do projeto (versão 1.0 publicada por João Paulo)

## Contexto

A Missão 02 pede "um pequeno módulo computacional" para cadastrar e classificar resíduos
eletrônicos, que depois possa ser incorporado ao aplicativo do grupo. O foco da
disciplina é a matemática (aritmética modular), não a interface.

- O grupo trabalha com Java.
- O enunciado não exige interface gráfica nem persistência.
- O prazo é curto e o módulo é experimental.

## Decisão

> Vamos construir o módulo como um programa de terminal em Java, com menu numérico no
> `Main`, usando Maven apenas como estrutura de projeto, sem bibliotecas externas.

O `pom.xml` declara Java 25 (`maven.compiler.source/target`) e nenhuma dependência.
A entrada é feita com `Scanner(System.in)`.

## Alternativas consideradas

### Alternativa 1: Interface gráfica (Swing ou JavaFX)

- **Prós:** apresentação mais bonita.
- **Contras:** muito mais código, sem ganho para o objetivo da atividade.
- **Por que não foi escolhida:** desviaria o esforço da parte matemática.

### Alternativa 2: Projeto Java sem Maven

- **Prós:** nenhuma configuração.
- **Contras:** sem estrutura padrão, mais difícil de adicionar testes ou bibliotecas depois.
- **Por que não foi escolhida:** Maven custa só um `pom.xml` e prepara o projeto para crescer.

## Consequências

### Positivas

- Roda em qualquer máquina com JDK 25, sem instalar nada além disso.
- O menu deixa claro, na apresentação, qual etapa do enunciado cada opção atende.

### Negativas

- Exige JDK 25, versão recente; máquinas do laboratório com Java 17 ou 21 não compilam
  sem mudar o `pom.xml`.
- `sc.nextInt()` no menu não trata entrada inválida: digitar uma letra encerra o
  programa com `InputMismatchException`.

### Neutras

- O pacote `Resíduo` usa acento no nome. Compila na IDE, mas falha com `javac` em
  ambientes cujo terminal não está em UTF-8 ("Invalid filename").

## Riscos e pendências

- [ ] Avaliar baixar o alvo para Java 21 (LTS) se algum integrante não tiver o 25.
- [ ] Renomear o pacote `Resíduo` para um nome sem acento.
