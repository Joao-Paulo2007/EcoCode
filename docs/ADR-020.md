# ADR-020: Ler a chave da cifra de um arquivo .env com dotenv-java

- **Status:** Aceita
- **Data:** 2026-10-23
- **Autores:** Grupo do projeto

## Contexto

A Cifra de César (ADR-019) precisa de uma chave. Deixar o número escrito no código faz a
chave ir para o GitHub junto com o projeto. O grupo também quer um lugar único para as
configurações futuras, como caminhos de arquivos e dados de banco.

## Decisão

> Vamos guardar a chave como variável de ambiente num arquivo `.env`, lido com a biblioteca
> `dotenv-java`, através de uma classe `Configuracao`.

- O `.env` fica na raiz do projeto, com `CHAVE_CIFRA=<número>`.
- `Configuracao.getChaveCifra()` lê a variável, avisa se ela não existir ou não for um
  inteiro, e normaliza com `Math.floorMod(..., 26)`.
- O `.env` está no `.gitignore`; um `.env.example` sem o valor real vai para o repositório.

## Alternativas consideradas

### Alternativa 1: Chave fixa no código

- **Prós:** nenhuma configuração.
- **Contras:** a chave fica pública no repositório.
- **Por que não foi escolhida:** contraria a ideia de proteger os dados.

### Alternativa 2: Ler o arquivo com `java.util.Properties`

- **Prós:** sem dependência externa.
- **Contras:** não lê variáveis de ambiente do sistema.
- **Por que não foi escolhida:** a `dotenv-java` serve também para as configurações futuras.

### Alternativa 3: Uma chave diferente para cada item cifrado

- **Prós:** cada dado teria uma chave própria.
- **Contras:** a chave de cada item precisaria ser guardada ou calculada para decifrar.
- **Por que não foi escolhida:** o grupo decidiu manter uma chave única por enquanto.

## Consequências

### Positivas

- A chave pode ser trocada sem recompilar.
- Cada integrante usa o seu próprio `.env`.

### Negativas

- Primeira dependência externa do projeto, no `pom.xml`.
- Quem não tiver o `.env` não consegue rodar a cifra.
- A `CifraCesar` lê a `Configuracao` no próprio campo, então cada instância lê o `.env` e a
  chave fica fixa no objeto.
- O `.env` chegou a ser enviado ao GitHub antes de ser removido do rastreamento; a chave
  antiga continua visível no histórico.

## Riscos e pendências

- [ ] Trocar o valor de `CHAVE_CIFRA`, já que a chave antiga ficou no histórico do GitHub.
- [ ] Fazer a cifra receber a chave como parâmetro e a `Configuracao` ser lida só por quem
  chama.
