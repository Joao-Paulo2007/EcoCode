# ADR-023: Guardar a senha do usuário cifrada com a Cifra de César

- **Status:** Aceita
- **Data:** 2026-10-24
- **Autores:** Grupo do projeto

## Contexto

O módulo de usuários (ADR-022) precisa guardar a senha. Guardar em texto puro deixaria a
senha legível para quem acessar os dados. O projeto já tem a Cifra de César implementada para
a Missão 03 (ADR-019, ADR-021), com a chave lida do `.env` (ADR-020).

## Decisão

> Vamos guardar a senha do usuário cifrada com a `CifraCesar`, no cadastro e na edição, no
> campo `senhaCriptografada`.

- O service chama `cifraCesar.cifraCesar(senha)` antes de criar ou editar o usuário.
- A chave usada é a mesma `CHAVE_CIFRA` do `.env`.

## Alternativas consideradas

### Alternativa 1: Senha em texto puro

- **Prós:** nenhuma conversão.
- **Contras:** qualquer pessoa que abrir os dados lê todas as senhas.
- **Por que não foi escolhida:** contraria o objetivo da Missão 03.

### Alternativa 2: Hash com algoritmo próprio para senhas (BCrypt)

- **Prós:** não tem volta, nem para quem tem acesso ao sistema; cada senha recebe um
  "sal" diferente, então senhas iguais geram resultados diferentes. É o que sistemas reais
  usam.
- **Contras:** exige uma biblioteca externa e foge do conteúdo da disciplina.
- **Por que não foi escolhida:** o grupo quis aplicar a cifra estudada na missão.

## Consequências

### Positivas

- A senha não fica legível à primeira vista.
- Reaproveita a cifra que o trabalho já pede.

### Negativas

- **A proteção é fraca.** A Cifra de César tem só 26 chaves, e o próprio projeto tem a força
  bruta (`descriptografarTodasChaves`) que recupera qualquer senha em 26 tentativas.
- **A cifra tem volta.** Quem tiver a chave do `.env` lê todas as senhas. Essa chave já ficou
  exposta no histórico do GitHub (ADR-020).
- **Senhas iguais geram o mesmo texto cifrado**, revelando que dois usuários usam a mesma
  senha.
- **Trocar a chave do `.env` invalida todas as senhas salvas**, porque elas foram cifradas
  com a chave anterior.
- Dígitos e caracteres especiais da senha não são cifrados (ADR-021).

### Neutras

- No login, a senha digitada deve ser cifrada com a mesma chave e comparada com a salva; não
  é preciso decifrar a senha guardada.

## Riscos e pendências

- [ ] Trocar a Cifra de César por um hash de senha (BCrypt) antes de usar o sistema com
  dados reais.
- [ ] Registrar no relatório que a cifra é usada aqui como exercício da disciplina, não como
  proteção adequada para senhas.
