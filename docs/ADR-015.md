# ADR-015: Calcular a classe pelo código no service, no lugar do Classificador estático

- **Status:** Aceita
- **Data:** 2026-10-23
- **Autores:** Grupo do projeto

## Contexto

Na versão 1.0, a classe estática `Classificador` mapeava texto para resto e resto para
categoria (ADR-007). Com o enum `TipoResiduo` (ADR-012), a tabela de categorias passou a
morar no enum, e a classe ficou sem função. A Etapa 2 continua pedindo que o programa
mostre a classe calculada por h(k) = k mod 5.

Durante a refatoração, a classificação chegou a ler o resto direto do enum
(`getResto()`), sem fazer conta nenhuma.

## Decisão

> Vamos calcular a classe no service, a partir do código, com `Integer.parseInt(codigo) % 5`,
> em vez de ler o resto guardado no enum.

- `calcularClasse(residuo)`: devolve o resto calculado pelo código.
- `classeConfere(residuo)`: confere se a classe calculada é igual ao resto do tipo.

O resto do enum é a entrada do gerador ("preciso de um código com resto 2"); o resto
calculado é o resultado da conta. Exibir o calculado é o que mostra a aritmética modular
na tela.

## Alternativas consideradas

### Alternativa 1: Mostrar o resto guardado no enum

- **Prós:** nenhuma conta.
- **Contras:** a Etapa 2 parece cumprida, mas o mod 5 não acontece; um código inconsistente
  passaria despercebido.
- **Por que não foi escolhida:** a missão é uma auditoria, e auditar é conferir o
  resultado, não repetir o esperado.

### Alternativa 2: Manter uma classe utilitária só para o cálculo

- **Prós:** isola a regra matemática.
- **Contras:** uma classe inteira para um `% 5`, com risco de a conta ficar em dois lugares.
- **Por que não foi escolhida:** o grupo preferiu um método no service.

## Consequências

### Positivas

- A conta da Etapa 2 aparece de verdade no programa.
- `classeConfere` detecta códigos que não correspondem ao tipo, como um dado importado ou
  editado à mão no futuro.

### Negativas

- Como o gerador sempre escolhe um código compatível, `classeConfere` hoje sempre devolve
  `true`.

## Riscos e pendências

- [ ] Definir onde a classe calculada é exibida, depois da remoção da opção "Classificar
  resíduos" do menu (por exemplo, na listagem).
- [ ] Remover `classeConfere` se nenhuma tela usar.
