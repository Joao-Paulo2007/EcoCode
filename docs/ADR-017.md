# ADR-017: Filtrar a listagem por categoria no service

- **Status:** Aceita
- **Data:** 2026-10-23
- **Autores:** Grupo do projeto

## Contexto

Além de listar tudo, o grupo quis consultar os resíduos de uma categoria só, por exemplo
para saber quantas baterias foram descartadas. Isso não é pedido pelo enunciado; é um
recurso de uso do aplicativo.

## Decisão

> Vamos implementar `listarPorTipo(TipoResiduo)` no service, filtrando a lista que vem do
> repositório, e mostrar na tela os resíduos da categoria com o total de unidades.

- O usuário escolhe a categoria com o mesmo menu do cadastro (`lerTipoResiduo()`).
- O service percorre `listar()` do repositório e guarda os itens cujo tipo é igual ao
  escolhido (comparação com `==`, por ser enum).
- A tela mostra cada resíduo e, no fim, quantos cadastros e quantas unidades há na
  categoria.

## Alternativas consideradas

### Alternativa 1: Método de busca por tipo no repositório

- **Prós:** a consulta fica na camada de dados, o que será natural com um banco.
- **Contras:** com o `Map` em memória, o repositório faria o mesmo laço.
- **Por que não foi escolhida:** o repositório não precisou mudar; ao migrar para banco,
  a consulta pode descer para ele.

## Consequências

### Positivas

- Nenhuma mudança no repositório.
- O menu de tipos é reaproveitado.

### Negativas

- O filtro percorre todos os resíduos a cada consulta.

### Neutras

- Diferente da classificação (ADR-015): a classificação mostra a conta do mod 5; esta
  listagem só filtra pelo tipo.
