# ADR-019: Implementar a Cifra de César sobre a correspondência A = 0 ... Z = 25

- **Status:** Aceita
- **Data:** 2026-10-23
- **Autores:** Grupo do projeto

## Contexto

A Missão 03 pede para proteger os dados do aplicativo com cifras clássicas. As etapas 1 a 4
pedem a correspondência entre letras e Z₂₆, a Cifra de César E(x) = (x + k) mod 26, a
decifragem e a quebra da cifra testando todas as chaves.

## Decisão

> Vamos implementar a cifra na classe `CifraCesar`, com o alfabeto numa `String` constante,
> conversão letra/número por posição e `Math.floorMod` para a volta no alfabeto.

| Método | Faz |
| --- | --- |
| `letraEmValor(char)` | `indexOf` na constante, após converter para maiúscula; `-1` se não for letra |
| `valorEmLetra(int)` | `charAt`; erro se o valor estiver fora de 0 a 25 |
| `cifraCesar(mensagem)` | (x + k) mod 26 em cada letra |
| `decifraCesar(mensagem)` | (y − k) mod 26 em cada letra |
| `descriptografarTodasChaves(mensagem)` | Lista com a mensagem decifrada pelas 26 chaves; a posição na lista é a chave |

- Caracteres que não são letras (espaço, número, pontuação, acentos, Ç) passam sem mudar.
- A mensagem é percorrida com `for-each` em `toCharArray()` e montada com `StringBuilder`.
- `Math.floorMod` é usado no lugar de `%`, porque `%` devolve negativo na decifragem.

## Alternativas consideradas

### Alternativa 1: Alfabeto em array ou lista

- **Prós:** acesso por índice.
- **Contras:** achar a posição de uma letra exige um laço.
- **Por que não foi escolhida:** a `String` já oferece `indexOf` e `charAt`.

### Alternativa 2: Usar o código do caractere (`letra - 'A'`)

- **Prós:** mais curto.
- **Contras:** esconde a correspondência entre o alfabeto e Z₂₆ que a Etapa 1 pede.
- **Por que não foi escolhida:** a `String` deixa essa função visível.

## Consequências

### Positivas

- Testado com os casos do enunciado: `RECICLA` com chave 3 vira `UHFLFOD` e volta ao
  original; `XYZ` vira `ABC`.
- A volta no alfabeto funciona nos dois sentidos.

### Negativas

- A saída é sempre em maiúsculas; comparar com o original exige `equalsIgnoreCase`.
- Letras acentuadas não são cifradas.
- O laço da força bruta repete o código do `decifraCesar`; uma mudança na decifragem
  precisa ser feita nos dois lugares.
- A cifra tem só 26 chaves e é quebrada por força bruta: serve para estudo, não para
  proteger dados de verdade (senhas devem usar hash, como BCrypt).

## Riscos e pendências

- [ ] Extrair um método privado que decifra com uma chave recebida, usado pelo
  `decifraCesar` e pela força bruta.
