# ADR-011: Guardar os resíduos num TreeMap com o código como chave

- **Status:** Aceita
- **Data:** 2026-10-22
- **Autores:** Grupo do projeto

## Contexto

A versão 1.0 guardava os resíduos numa `ArrayList` (ADR-003), o que bastava para listar e
contar. A refatoração trouxe busca, edição e exclusão por código. Com uma lista, cada uma
dessas operações precisaria percorrer todos os itens, e nada impediria dois resíduos com o
mesmo código.

## Decisão

> Vamos guardar os resíduos num `Map<String, Residuo>`, usando o código como chave, com a
> implementação `TreeMap`.

| Operação do repositório | Implementação |
| --- | --- |
| `salvar(residuo)` | `put(codigo, residuo)` |
| `editar(residuo)` | `put(codigo, residuo)`, que substitui o anterior |
| `excluir(codigo)` | `remove(codigo)` |
| `buscar(codigo)` | `get(codigo)`, que devolve `null` se não existir |
| `listar()` | `new ArrayList<>(values())`, uma cópia |

## Alternativas consideradas

### Alternativa 1: Manter a `ArrayList`

- **Prós:** estrutura conhecida pelo grupo.
- **Contras:** busca, edição e exclusão viram laços; editar com `add` duplicaria o item.
- **Por que não foi escolhida:** o `Map` faz cada operação numa chamada só.

### Alternativa 2: `HashMap`

- **Prós:** um pouco mais rápido.
- **Contras:** a ordem da listagem fica imprevisível.
- **Por que não foi escolhida:** o `TreeMap` lista sempre em ordem de código.

## Consequências

### Positivas

- Código repetido é impossível: a chave do `Map` é única.
- Busca, edição e exclusão vão direto na chave.
- A listagem sai ordenada por código, sem `sort`.
- `listar()` devolve uma cópia, então quem chama não altera os dados internos.
- Conversa com o tema de hashing do enunciado: o `Map` é uma tabela indexada pela chave.

### Negativas

- A busca só funciona com o código no formato salvo (`"0005"`); por isso o service
  normaliza o código digitado antes de buscar (ADR-013).
- O `TreeMap` ordena texto, não número. Funciona enquanto todos os códigos tiverem o mesmo
  tamanho; acima de 9999, `"10000"` ficaria antes de `"2000"`.
- Os dados continuam só em memória e somem ao fechar o programa.

## Riscos e pendências

- [ ] Criar a versão do repositório que salva em JSON, mantendo a mesma interface.
